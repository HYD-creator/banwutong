# 班务通｜公告管理模块设计

## 1. 模块目标

公告管理用于班主任向班级发布文字通知，以及临时呼叫学生。信息由教师管理模式发起，自动同步到教室展示模式。

## 2. User Story

### 2.1 班级公告

- 作为班主任，我可以发布纯文本公告，让全班及时看到通知。
- 作为班主任，我可以选择立即发布或设置未来的开始时间。
- 作为班主任，我可以设置结束时间；未设置时公告长期有效。
- 作为班主任，我可以修改、删除公告，并查看当前、待发布及历史公告。
- 作为班主任，我可以将历史公告复制为一条新公告再次发布。
- 作为教室中的查看者，我可以看到新公告自动弹出，并点击“已收到”关闭。
- 作为教室中的查看者，关闭弹窗后仍可以在班级公告页面重新查看有效公告。

### 2.2 学生呼叫

- 作为班主任，我可以选择一名学生进行呼叫。
- 作为班主任，我可以快速选择“请到讲台”或“请到教师办公室”。
- 作为班主任，我也可以填写自定义呼叫内容。
- 作为教室中的学生，我可以在醒目弹窗中看到被呼叫学生和呼叫内容。
- 作为教室中的查看者，我可以点击“已知晓”关闭呼叫。
- 作为班主任，我可以查看最近两条学生呼叫及其回应状态。

## 3. 产品流程

### 3.1 发布公告

教师进入公告管理 → 发布公告 → 填写正文 → 设置开始/结束时间 → 发布 → 到达开始时间后同步到教室端 → 自动弹窗 → 点击“已收到” → 弹窗关闭但公告继续保留在列表 → 到期后自动归入历史记录。

### 3.2 修改公告

教师打开当前或待发布公告 → 修改正文或时间 → 保存 → 清除原“已收到”状态 → 教室端重新弹出最新内容。

### 3.3 重新发布

教师在历史记录点击“重新发布” → 系统带入原公告正文但清空旧时间 → 教师确认新时间 → 生成一条新公告，旧记录继续保留。

### 3.4 学生呼叫

教师点击“呼叫学生” → 选择学生 → 选择预设内容或输入自定义内容 → 立即呼叫 → 教室端优先弹出 → 点击“已知晓” → 显示下一条未确认信息。

## 4. 功能规则

- 公告仅支持文本，最多 500 字。
- 开始时间为空时立即展示；结束时间为空时长期有效。
- 结束时间必须晚于开始时间或当前时间。
- 公告状态分为：未开始、展示中、已结束。
- 已结束公告自动归档，不自动删除。
- 删除公告后不保留，并同步从教室端消失。
- 修改展示中公告后，教室端需要重新确认。
- 多条未确认信息逐条弹出；学生呼叫优先于普通公告，同类信息按最新优先。
- “已收到/已知晓”仅代表教室大屏统一确认，不记录具体学生。
- 学生呼叫不设置结束时间，确认后结束展示。
- 学生呼叫仅保留最近两条记录。
- 公告与呼叫均不使用提示音，只进行视觉提醒。

## 5. 页面结构

### 5.1 教师管理模式

- 顶部操作：呼叫学生、发布公告。
- 学生呼叫：最近两条及“等待回应/已知晓”状态。
- 当前公告：正在展示的公告。
- 待发布：设置了未来开始时间的公告。
- 历史记录：已经结束的公告，可重新发布或删除。

### 5.2 教室展示模式

- 新公告弹窗：突出正文，显示发布人和发布时间。
- 学生呼叫弹窗：突出学生姓名和呼叫内容。
- 班级公告页面：重新查看全部有效公告。
- 多条消息：确认当前弹窗后自动显示下一条。
